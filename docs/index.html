Simple on the outside, careful underneath

Built with a parent-controlled boundary

Game metadata never becomes a shell command. Every import is validated, staged, and approved before it appears in the child’s library.

  • Allowlisted emulator adapters
  • Versioned, validated manifests
  • Isolated saves and configuration
  • Traversal and symlink protection
  • Structured launch diagnostics
  • No ROMs or firmware in the repository
